# Primrose dessert

Site vitrine + catalogue + commande WhatsApp pour Primrose dessert.

## Structure

- `index.html` — page unique (HTML/CSS/JS autonome, aucune dépendance à installer)

## Déploiement

Ce fichier peut être hébergé tel quel avec **GitHub Pages** :

1. Poussez `index.html` à la racine du dépôt
2. Repo → Settings → Pages → Branch: `main` / dossier `/ (root)` → Save
3. Le site sera disponible à `https://<votre-utilisateur>.github.io/<nom-du-repo>/`

## À vérifier avant mise en ligne

Les prix dans `PRODUCTS` (script en bas de `index.html`) ne correspondent pas
à ceux annoncés par le Copilote dans les règles `COPILOT_RULES` — à aligner.
